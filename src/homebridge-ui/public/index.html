eufy NVR Gateway
The gateway's address, with its port if it isn't 8099 (e.g. 192.168.1.10:8099).

The gateway's stream login ("rtsp" in its config.json), the one your NVR uses. Homebridge plays the streams with it, and finds and wakes the cameras with it.

Only for gateways before 0.6.0, which don't accept the stream login for finding and waking cameras: the login of the gateway's web page ("web" in its config.json). Updating the gateway makes this unnecessary.
